## 📋 Description

**My Quality System** is a web application for comprehensive organizational quality management. It provides real-time visibility into the quality system status through an interactive dashboard, manages internal and external audits, tracks non-conformities, and controls the lifecycle of quality processes.

---

## ✨ Features

| Module | Description EN |
|---|---|
| 📊 **Dashboard** | Real-time KPI metrics and indicators with interactive charts |
| 🔍 **Auditorías** | Full lifecycle management of internal and external audits |
| ⚠️ **No Conformidades** | Registration, tracking and closure of non-conformities with traceability |
| ⚙️ **Procesos** | Status and performance tracking of quality processes |

## 🛠️ Tech Stack

- **Framework:** [React 19](https://react.dev/) + [Vite 7](https://vite.dev/)
- **Styles:** [Tailwind CSS 4](https://tailwindcss.com/)
- **UI Components:** [Radix UI](https://www.radix-ui.com/) (Dialog, Select, Switch, Progress, ScrollArea…)
- **Charts:** [Recharts](https://recharts.org/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Dates:** [date-fns](https://date-fns.org/)
- **Notifications:** [Sonner](https://sonner.emilkowal.ski/)
- **Deploy:** [GitHub Pages](https://pages.github.com/) via `gh-pages`

## 🚀 Installation & Usage

### Requirements

- **Node.js** ≥ 18
- **npm** ≥ 9

### Steps
```bash
# 1. Clone the repository
git clone https://github.com/faidrn/my-quality-system.git
cd my-quality-system

# 2. Install dependencies
npm install

# 3. Start the development server
npm run dev
```

Open your browser at: **http://localhost:5173**
